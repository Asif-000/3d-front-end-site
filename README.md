# 3d-front-end-site
This project is a visually engaging and responsive landing page designed to showcase modern front-end capabilities. It combines scroll-triggered animations with an interactive 3D model to create a dynamic user experience. The page is built using HTML, CSS, and JavaScript, with integrations including AOS (Animate on Scroll) for smooth animation effects and Spline for rendering 3D content directly in the browser.

The layout includes a gradient background, animated header and navigation, a headline section with call-to-action buttons, and a 3D model embedded using the Spline viewer. The design emphasizes clean UI, animation fluidity, and component modularity — suitable for a portfolio, product launch, or promotional page.

## 🚀 Features
- Responsive design
- Scroll animations with AOS
- Embedded Spline 3D scene
- Simple and clean UI

## 🔧 Technologies Used
- HTML5
- CSS3
- AOS (Animate on Scroll)
- Spline Viewer (Web Component)
